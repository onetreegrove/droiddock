# DroidDock UI 设计稿说明

设计日期：2026-04-25

## 设计目标

DroidDock 面向非技术用户，因此 UI 需要隐藏命令行细节，把 `adb`、`scrcpy`、USB、无线连接、ADB Pair 等概念转化为清晰的流程和状态。

第一版 UI 不承载投屏画面。投屏画面由 `scrcpy` 独立窗口负责，DroidDock 负责设备发现、连接配置、投屏启动、会话管理和排障。

## 信息架构

主导航分为四个区域：

1. 首页
   - 工具状态
   - 快速连接
   - 当前投屏会话

2. 设备
   - USB 设备
   - 无线设备
   - 最近连接
   - 设备别名

3. 连接向导
   - USB 连接
   - USB 转无线
   - ADB Pair 配对
   - 当前无线设备重连

4. 设置
   - 自动安装工具
   - 手动配置 `adb` 路径
   - 手动配置 `scrcpy` 路径
   - 工具版本和诊断日志

## 核心界面

### 首次启动

目标：让非技术用户明确当前缺什么、下一步要做什么。

关键模块：

- `adb` 状态
- `scrcpy` 状态
- 自动安装按钮
- 手动选择路径按钮
- 安装来源和安全说明

### 主控台

目标：快速看到设备、连接状态和投屏会话。

关键模块：

- 顶部工具状态
- 左侧设备列表
- 中部连接方式选择
- 右侧当前会话
- 底部过程日志

### ADB Pair 配对

目标：降低 pair/connect 两个端口的理解成本。

界面必须分开：

- 配对地址和配对端口
- 配对码
- 连接地址和连接端口

界面文案强调：

- 配对码不会保存。
- 配对端口和连接端口通常不同。
- 配对成功后还需要连接。

### 当前无线设备重连

目标：让用户修正当前离线无线设备的 IP 或连接端口后重新连接。

入口必须来自具体设备：

- 设备列表中当前无线设备的重连按钮。
- 设备详情中当前无线设备的重连按钮。

界面必须默认填入当前设备本地保存的连接地址：

- 设备 IP
- 连接端口

界面不展示“最近连接记录”。最近连接是全局历史，而重连弹窗服务的是当前设备，避免用户把其他设备的 endpoint 套到当前设备上。

界面文案强调：

- 手机重启或无线调试重新开启后，连接端口可能变化。
- 以手机“无线调试”页面显示的 IP 和端口为准。
- 重连成功后会更新当前设备保存的连接地址。

设备详情当前会话区主按钮规则：

- USB 在线设备：显示“启动投屏”。
- 无线在线设备：显示“启动投屏”。
- USB 离线设备：禁用，并提示插入 USB 后自动刷新。
- 无线离线且有保存的 endpoint：显示“恢复连接”。
- 无线离线但没有保存的 endpoint：禁用，并提示重新配对或通过 USB 转无线。

当前会话区在未投屏、未连接和最近停止时标题显示“会话”，右侧状态 badge 显示“已连接”或“未连接”；投屏中仍显示“当前会话 / 投屏中”。状态 badge 只表达状态，不抢主操作注意力；说明信息栏采用左右两栏，左侧展示“可以开始投屏 / 先恢复设备连接”等可执行说明，右侧展示高优先级主操作按钮。

从“恢复连接”进入重连弹窗时，弹窗主按钮显示“恢复连接”。连接成功后只更新用户确认的新 endpoint，不自动启动投屏；连接恢复后用户可在当前会话区点击“启动投屏”。

### 多设备会话

目标：允许同时管理多台手机投屏。

每个会话展示：

- 设备名
- 连接方式
- 投屏状态
- scrcpy 窗口状态
- 停止按钮
- 重连按钮
- 日志入口

## 视觉原则

- 工具型应用，不做营销页。
- 控件密度适中，优先清晰和可扫描。
- 主色使用绿色，表示可连接和运行状态。
- 警告使用琥珀色。
- 错误使用红色。
- 设备和会话状态使用稳定色块，减少用户判断成本。
- 不使用大面积渐变、装饰性图形或复杂动效。

## 状态文案

建议把底层错误转译成用户可执行文案。

| 底层状态 | UI 文案 |
| --- | --- |
| `unauthorized` | 请解锁手机，并在手机弹窗中允许 USB 调试 |
| `offline` | 设备已离线，请重新插拔数据线或重新连接无线调试 |
| `Connection refused` | 无线调试端口不可用，请检查 IP、端口和手机无线调试是否开启 |
| `failed to authenticate` | 配对失败，请重新生成配对码后再试 |
| `more than one device/emulator` | 当前有多台设备，请先选择要投屏的手机 |
| `adb: unknown command pair` | 当前 adb 版本不支持无线配对，请升级 Platform Tools |
